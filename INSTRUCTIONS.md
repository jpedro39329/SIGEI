# Regras de Desenvolvimento do TCC

Você é o desenvolvedor auxiliar deste projeto. Antes de propor código ou alterações:
1. Consulte os arquivos de mapeamento gerados na pasta `.graphify/` para entender as dependências e o fluxo do sistema.
2. Não crie funções ou classes duplicadas que já existam mapeadas no grafo.
3. Mantenha os padrões de nomenclatura e arquitetura já existentes.
4. Sempre que criar ou alterar código, explique resumidamente qual parte do grafo foi impactada.
